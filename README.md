# BRAINFRAME OS LITE: Standalone Lean Agentic Framework

Agentic workflows shouldn't be locked behind expensive, high-spec rigs or massive cloud bills. 

**BRAINFRAME OS LITE** is a fully self-contained, independent AI Operating System designed to democratize automation. It is engineered specifically to run complex, multi-tiered agentic loops entirely on **legacy, low-spec, or budget-restricted hardware**—including 10-to-12-year-old machines with as little as **4GB of RAM**. 

While built to stand completely on its own feet as a localized command center, BRAINFRAME OS LITE possesses the native ability to hook into a decentralized cluster, serving as a physical "Hardware Arm" and Edge Tool Node for larger installations.

---

## What This Is: Standalone OS with Edge Extensibility

BRAINFRAME OS LITE is not a subordinate background utility; it is a peer operating system running its own sovereign logic loops. 

| Edition | Architectural Status | Target Environment |
| :--- | :--- | :--- |
| **BRAINFRAME OS LITE** *(This Repo)* | **Independent Standalone OS.** Coordinates localized files, local workflows, and terminal operations linearly. *Optional Capability:* Can expose an encrypted hook to act as an Edge Node. | Legacy Hardware / Local Base Workstations (Less than 16GB RAM / Down to 4GB) |
| **BRAINFRAME OS FULL** | **Distributed Cluster Core.** Orchestrates massive parallel compute blocks and deep multi-agent project swarms. | Enterprise Servers / Advanced Cloud Instances (16GB RAM or higher) |

## API Integration & Model Prototyping (Free & Premium Tiers)

Because LITE runs within a restricted local hardware footprint, it delegates its cognitive processing entirely to cloud-based APIs. The framework is uniquely structured to allow a blend of premium user accounts and completely free developer API tiers to maximize capability while deflecting rate limits.

### 1. The Executive Gateway (Premium VP Pools & Telegram Hub)
The localized **VP Council** can be hooked directly into your personal premium subscriptions. Any of these can be assigned as your main primary executive engine, with the others automatically serving as real-time fallbacks. 

To clear up any confusion: **these are labeled as "Bots" because each backend engine layer is explicitly mapped to a standalone Telegram Bot token.** This allows you to receive direct context updates, error logs, or issue top-down overrides inside isolated chat windows:
* **Claude Code Bot** (Powered via Anthropic API / Claude Pro integration)
* **OpenAI Codex Bot** (Powered via OpenAI API / ChatGPT Pro integration)
* **Antigravity CLI Bot (`agy cli`)** (Powered via Google API / Google Pro integration)

### 2. The Operational Labor Layer (Distributed Free APIs)
To keep background operations running at a high level of intelligence without draining your premium subscription tokens, **Agent Zero** (which also possesses its own dedicated Telegram Bot link for instant 2FA bypasses) and the **PicoClaw** sub-agents operate on a distributed multi-model framework. 

By utilizing free public infrastructure, you can bypass Requests Per Minute (RPM) caps by assigning different smart models to individual agents:
* **Agent Zero (Operations Manager):** Programmed to use a highly intelligent, robust endpoint (such as an advanced model routed through open or low-cost endpoints) to ensure stable logic processing and file management.
* **PicoClaw "Claw OPs" (Operatives):** When tasks are broken down into granular execution steps, the sub-agents function as specialized "Claw OPs." To avoid hitting provider limits, each OP is assigned a completely distinct model variant, distributing the workload across independent server allocations:
    * **Claw OP 1:** Routed to model families on **Nvidia Build API (NIMs)** (e.g., Nemotron, specialized variants)
    * **Claw OP 2:** Routed to alternative pipelines on **OpenRouter Free API** (e.g., Qwen, Kimi, miniMax variants)

> 💡 **Rate-Limit Deflection:** Because API platforms track traffic thresholds per individual model endpoint, distributing your Claw OPs across distinct models allows your local runtime environment to safely scale past standard developer caps on zero-cost tiers.

## Shorthand Guide: Creating Your Telegram Bot Matrix

To link your physical device deployment to the asynchronous command highway, you must provision an independent bot for each operational block. Follow this shorthand configuration process:

1. **Initialize the Bots:** Open Telegram and message the official account `@BotFather`.
2. **Generate Endpoints:** Issue the command `/newbot` for each layer required (e.g., one for the VP Council, one for Agent Zero). Follow the prompts to assign a name and a unique username ending in `_bot`.
3. **Capture Cryptographic Tokens:** Copy the unique HTTP API token provided by BotFather for each generated endpoint (formatted as `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).
4. **Acquire Target Chat ID:** Search for the utility account `@userinfobot` or `@IdBot` on Telegram and send it a message. Copy your unique numerical integer account string (`CHAT_ID`). This locks the bots so they *only* listen and respond to your specific human identity.
5. **Bind to Environment Vault:** Paste these strings directly into your local, git-ignored configuration vault file (`.env` or `vault/secrets.json`):

```bash
# Telegram Global Routing Settings
ADMIN_CHAT_ID="<YOUR_NUMERICAL_CHAT_ID>"

# Executive Gateway Layer Tokens
TELEGRAM_TOKEN_CLAUDE_VP="<TOKEN_FROM_BOTFATHER>"
TELEGRAM_TOKEN_CODEX_VP="<TOKEN_FROM_BOTFATHER>"
TELEGRAM_TOKEN_ANTIGRAVITY_VP="<TOKEN_FROM_BOTFATHER>"

# Operations Layer Tokens
TELEGRAM_TOKEN_AGENT_ZERO="<TOKEN_FROM_BOTFATHER>"
```

## LITE Mode: Hardware-Bounded Discipline

To safely run advanced AI agents on a **4GB RAM** threshold without locking up your host operating system, BRAINFRAME OS LITE replaces heavy parallel frameworks with strict, highly disciplined execution rules:

* **Sequential Labor:** Forces a "one-task-at-a-time" execution path. It builds, pauses, reviews, and tests sequentially rather than spawning resource-heavy parallel swarms.
* **Per-Process Caps:** Enforces strict memory ceilings on every single background process wrapper.
* **Single-Model Residency:** Ensures only one local helper model or agent context is actively resident in memory at any given moment.
* **Threshold Garbage Collection:** Triggers aggressive system memory flushes and runtime garbage collection immediately before initializing any new execution steps.
* **Lean Streaming:** Prioritizes line-by-line searching, filtering, and `grep` pipelines over loading entire large files directly into memory space.

## Native Desktop & Hardware Domain Powers

As a standalone desktop environment, LITE interacts natively with your hardware layer, filling critical gaps that isolated cloud servers or headless virtual machines cannot cross:

* **GUI Automation:** Drives native desktop applications and interacts directly with local window managers.
* **The Authentic Browser:** Handles interactive OAuth authorization flows and manual MFA entry points that fail completely in headless cloud sandboxes.
* **Secure Local Storage:** Safeguards API tokens, configuration files, and credentials locally inside your device’s native OS keychain.
* **Hardware Peripheral Access:** Acts as a direct bridge to local networks, file servers, USB configurations, and legacy hardware arrays.
* **Physical Presence Triggering:** Provides a human-style local interface for tapping security keys or clearing localized device verification checks.

## Optional Mode: Serving as an Edge Tool Node

When you want to link BRAINFRAME OS LITE to an external master cluster or a remote `BRAINFRAME OS FULL` deployment, LITE exposes a lightweight, bearer-gated HTTP API over your private mesh. This allows an external cloud framework to securely delegate physical hardware requirements to your LITE system:

```http
POST /run          ← Execute a localized shell/bash command on the LITE host
POST /files/read   ← Safely read a local file path and return the text stream
POST /files/write  ← Write data directly to a local directory
GET  /screenshot   ← Capture a visual diagnostic layout of the LITE desktop
```
